## 5. The standing question

The granularity mismatch above is my answer, and it is worth noting *why* the self-audit missed it.
The four shapes checked — second-lock-same-door, untested branches, counted proxy, unapplied
standard — are all properties of a **mechanism in isolation**. This is a fifth shape: a **scope
mismatch between a mechanism and its own stated justification**, visible only by reading the `why`
prose against the signal set it actually forgives. Worth adding to that vocabulary; the method of
checking predicted shapes rather than concluding by absence is right and should continue.

**[INFO, not a defect]** `exempt_pin_digest` uses `keys or frozenset(EXEMPT)`, so a caller cannot
ask for the empty set's digest while `EXEMPT` is non-empty. It cannot green anything wrongly today —
the sensitivity control passes a non-empty forged set — but it is a latent trap in a helper whose
whole job is answering "what does this set hash to".
