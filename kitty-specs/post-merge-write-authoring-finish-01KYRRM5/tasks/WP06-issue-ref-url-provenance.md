## Squad Hardening (BINDING — supersedes conflicting wording above)

- **T026 regex — match-then-filter, single regex (renata M3/M4 + operator note).** There is NO canonical `Priivacy-ai/spec-kitty` repo-slug constant, and deriving owner/repo from the git remote inside the pure text parser would inject non-determinism and break the tmp-repo fixtures. So:
  - Widen the SINGLE `_GH_ISSUE_PATTERN` to match **any** `github.com/<owner>/<repo>/issues/<n>` (capture owner/repo), keeping the issue number in **`match.group(1)`** (the existing `int(match.group(1))` at issue_matrix.py:99 must keep working — use a non-capturing outer alternation).
  - Anchor to **`/issues/` ONLY, never `/pull/`** (a PR URL must NOT be matched as an issue).
  - Fix the trailing boundary to admit `#`, `/`, and EOL (so `/issues/123#issuecomment-…`, `/issues/123)`, trailing slash are captured, not silently dropped).
  - **Same-repo vs cross-repo discrimination happens in PYTHON**, not in the regex, using the already-present `repo` column (`_ENTRY_FIELDS` includes `"repo"`, issue_matrix.py:121). SC-008's requirement is that a cross-repo URL does NOT **block** the completeness gate (a filter concern) — it may be recognized/recorded but must not create a gate-blocking row. This keeps ONE regex (satisfies C-011 "no second matcher") while making the same/cross split testable without a real remote.
- **T027 type clarity (renata m3).** `IssueReference` is a bare `NamedTuple` with NO `to_dict`/`from_dict` (those are on `IssueMatrixEntry`). So: (a) add `source_file` to the `IssueReference` NamedTuple for in-memory carriage — populated at BOTH construction sites (`issue_matrix.py:102` AND `issue_reference_discovery.py:113`); (b) persist provenance via `IssueMatrixEntry._ENTRY_FIELDS` (issue_matrix.py:112-122) — additive/back-compatible because `from_dict` uses `data.get(name)` (no schema migration).
- **T028 dedup carries provenance.** The dedup `seen: dict[int, str]` (discovery.py:108) must be re-keyed/re-typed to retain the **first-occurrence** `source_file` (not just the context string). A number in N files keeps its first source_file.
