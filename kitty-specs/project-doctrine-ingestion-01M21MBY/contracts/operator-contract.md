# Project doctrine operator contract

- Charter authoring commands delegate to canonical doctrine implementations.
- Five project artifact kinds retain canonical source files, graph references, manifest entries and provenance through activation and resynthesis.
- A profile cascade activates reachable procedure, directive, tactic and styleguide references; unreachable references are reported.
- Resynthesis resolves the proposed activated set across project, org and built-in layers before activation writes. Unsupported input fails without changing activations.
- Default first-load context includes explicitly activated project directives; explicit profile/procedure context resolves project artifacts.
- Glossary show resolves the same scoped seed terms as glossary list.

Verification: [acceptance transcript](../research/acceptance-transcript.md), automated regressions and acceptance-matrix.json.
