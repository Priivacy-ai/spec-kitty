## Objective

Rewrite the dispatch-net predicate `is_charter_empty` so that **applying a pack without compiling keeps the
generic-agent safety net engaged**, while a compiled bundle or a routable org/profile config disengages it.

unmatched dispatch hard-fail with `ROUTER_NO_MATCH`, i.e. *worse* than an empty project). Ship it first, alone.

## Guidance

### T001 — Rewrite `is_charter_empty` to bundle-presence + routability split

Replace the current URN/dimension-set predicate with the org-pack-safe form (synthesis-validated):

```python
def is_charter_empty(repo_root: Path) -> bool:
    if (repo_root / ".kittify/charter/charter.yaml").exists():
        return False                                  # compiled bundle → configured
    pc = PackContext.from_config(repo_root)
    if pc.org_roots != ():                     return False   # org packs → router-routable
    if pc.activated_agent_profiles is not None: return False  # explicit profiles → routable
    return True
```

Behaviour matrix to honour: empty→True (net fires); apply-no-compile→True (**#3104 fix**); apply+compile→False
(router runs, NO_MATCH honest); org-pack no-compile→False (no regression); agent-profile activation→False.
Reuse the `charter.bundle.CHARTER_YAML` constant if it is importable without pulling `src/charter`→
`specify_cli` the wrong way; otherwise a local `Path(".kittify/charter/charter.yaml")` is acceptable here
(this module already lives under `specify_cli`). **Do NOT inspect bundle contents** — presence only ("empty"
means bundle ABSENT, never "present but activations empty"), or you re-import the #3064 exhaustiveness trap.
