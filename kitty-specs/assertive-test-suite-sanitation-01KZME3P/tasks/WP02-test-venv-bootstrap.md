# WP02 — Shared Test-Venv Bootstrap Reliability

## Objective

Replace the fixed 60-second lock held across editable installation with a recoverable lease protocol that never publishes a partial venv and never steals a slow live build. This is test-harness infrastructure, not a product feature.

## Required State Machine

`ABSENT → BUILDING(owner_pid, process_start_token, heartbeat, temp_path) → VALIDATED → PUBLISHED`

- State mutation uses a short file lock.
- Builder releases lock during install and updates heartbeat every five seconds.
- Temp build is a unique sibling of final cache on the same filesystem.
- Waiter polls without lock; live/fresh owner wins.
- Dead owner, mismatched process-start token, or expired heartbeat is reclaimed under lock; clean only the recorded temp path.
- Builder validates Python executable, source-version marker, and editable import before publication.
- Reacquire lock, prove lease ownership, ensure final is absent/invalid, then rename validated temp to final. Never build in place.

## T007 — Red Slow/Concurrent Tests

- Extract small seams only as needed for deterministic time/process/rename injection.
- Test a builder whose install exceeds the former 60-second timeout while heartbeat remains fresh; waiter must not error or steal.
- Test two simultaneous fresh starts in real spawned OS processes: exactly one build function runs; both callers receive the same validated final. Thread-only or whole-function fake races do not satisfy #3283.
- Test that a consumer cannot resolve final executable before publication.
- Confirm tests fail against base behavior for the right reason before implementation.

## T008 — Recovery Tests

- Dead owner with stale heartbeat: next claimant cleans recorded temp and builds.
- PID reuse: same PID with different process-start token is abandoned.
- Crash after temp creation/before validation: recovery does not publish temp.
- Invalid published venv: quarantine/remove under lock, rebuild once.
- Crash after validation/before rename: recovery safely cleans/rebuilds.
- Kill a spawned builder mid-build and prove a second process reclaims only its recorded sibling temp path. Use real process/file-lock/publication behavior for race and crash acceptance; narrow clock/install seams may remain injected.
- Never delete arbitrary paths from corrupt state; validate temp is an expected cache sibling.

## T009 — Implementation

- Keep helpers private to `tests/conftest.py` unless testability demands a test-support module already within ownership (it does not; prefer module-private seams).
- Write lease state atomically and fail closed on malformed state.
- Heartbeat lifecycle must stop on success/failure and not keep pytest alive.
- Bound overall waiting with a diagnostic substantially larger than a valid install lease; timeout must report owner, age, state path, and recovery guidance.
- Preserve offline seed/install and source-version semantics.
