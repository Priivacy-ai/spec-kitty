`spec-kitty agent action implement WP01 --mission assertive-test-suite-sanitation-01KZME3P --agent codex --profile python-pedro`

## Objective

Create a deterministic mission-local auditor and immutable base evidence. It must discover test-like source independently from pytest, collect pytest state through hooks, reconcile both views, validate deep ledger shards later, and freeze the workload/environment inputs used by every other WP.

## T001 — Snapshot Engine

- Implement `evidence/audit.py` with `snapshot`, `validate`, and `aggregate` subcommands.
- Source discovery: parse all Python under `tests/`; record source function/class, decorators, path, zero-node state, and ignore/deselection configuration.
- Collection: invoke pytest in-process with a plugin object. Capture deterministic nodeid, parent source function, inherited markers, collection report errors, deselection, and skip/xfail/quarantine metadata. Do not use JUnit as inventory.
- Prevent recursion: auditor collection must not rediscover or execute itself; run `--collect-only`, `-p no:cacheprovider`, and record plugin/config versions.
- Stable sort every mapping/list where order is not semantic. Normalize only volatile timestamps/absolute temp roots; do not erase outcome differences.

## T002 — Immutable Base Census

- Target inventory SHA is `28ae75ea998c898aba57364db7a06d2088bd2af2`.
- Generate compact `base-census.json` from a disposable clean base surface or prove the checkout content hash matches the SHA for all test/config inputs.
- Include source-discovered but ignored, errored, deselected, quarantined, and zero-node units.
- Include exact-body duplicate fingerprints, but do not claim semantic equivalence from syntax alone.
- Reconcile every collected node and source test-like function; fail on missing/duplicate membership.

## T003 — Frozen Workload and Environment

- Record exact commands for full collection, full parallel suite, orphan sweep, regression route, quarantine route, contract, architectural, and sibling E2E gates.
- Store runner/OS, Python, CPU class, event, allowed env, `uv.lock` hash, install command/state, workers, cache policy, and #3283 patch hash field.
- Model route dependency edges needed for critical-path calculation.
- Preserve the raw #3283 lock cascade summary and the healthy prewarmed full-suite summary: 24 failed, 37,298 passed, 108 skipped, 5 xfailed, 2 errors, 1,689.48s.

## T004 — Validator

- Validate the typed fields and conditional rules in `data-model.md`.
- Global census is lightweight. Require deep rows only for deletes, consolidations, temporary exceptions, fixes, materially changed survivors, and survivors cited to justify deletion.
- Enforce family equivalence: production path, oracle, outcome, route role, cost class, platform, and disposition. Any divergence requires node rows.
- Enforce class-specific evidence profiles. Reject one-size evidence requirements.
- Reject terminal `FIX_*`; reject `TEMPORARY` without one-time HiC approval/owner/issue/≤30-day expiry, renewal, or use for inert/correctness/timing cases.

## T005 — Determinism and Anti-vacuity

- Use temporary fixture trees created at runtime, not permanent test files.
- Prove two identical snapshots are byte-identical after documented normalization.
- Inject zero-node, ignored, collection-error, inherited-marker, divergent-parameter, and duplicate-membership cases; prove correct reconciliation/failures.
- Prove an empty tests root produces an explicit zero census, not a fabricated pass.
- Run `ruff` and focused mypy on the mission-local script where practical; no suppressions hiding schema errors.

## T006 — Evidence Handoff

- Write compact raw artifacts and SHA-256 hashes. Do not copy the entire 28-minute log when a complete node/outcome summary plus hash is sufficient.
- Generate complete class manifests for inert candidates, exact-body groups, promoted semantic groups, and structural/source/AST/text scanners under every test root. Resolve every entry to exactly one downstream WP and editable path owner.
- Fail closed before class dispatch when any candidate/group is unowned. Amend tasks/ownership, rerun `finalize-tasks`, and record the replan; “out of scope” is not a sanitation verdict.
- `foundation-summary.yaml` records counts, commands, environment IDs, discovery/collection reconciliation, and known raw artifacts.
- Keep human prose derived and minimal; raw + schema are authority.
- After the immutable foundation is approved, ownership of `audit.py` transfers to WP08 solely for truthful HEAD-role validation, fail-closed aggregate coverage, and closure-time CLI compatibility. WP08 may not rewrite the frozen base census or workload.
- Commit all owned files and mark T001–T006 complete.
