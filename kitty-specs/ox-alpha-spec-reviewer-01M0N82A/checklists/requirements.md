# Чек-лист качества спецификации

- [x] Цель сформулирована через пользовательский результат, а не реализацию.
- [x] Ручной opt-in, disclosure summary и одноразовое consent заданы явно.
- [x] Внешняя отправка ограничена одним каноническим `spec.md` и рубрикой.
- [x] Advisory-результат не изменяет спецификацию и не блокирует workflow.
- [x] Все функциональные требования имеют уникальные ID и проверяемый исход.
- [x] Нефункциональные требования содержат измеримые пороги.
- [x] Ошибки CLI, auth, timeout, provider и формата различаются.
- [x] Указаны границы privacy, credential ownership и логирования.
- [x] Бесплатность, доступность и zero-data-retention не заявлены как гарантии.
- [x] Сценарии success, failure, повторного и конкурентного запуска покрыты.
- [x] Scope v1 отделён от автоматизации, UI, multi-provider и auto-fix.
- [x] Критерии успеха проверяемы без live-модели; live smoke отделён opt-in gate.
