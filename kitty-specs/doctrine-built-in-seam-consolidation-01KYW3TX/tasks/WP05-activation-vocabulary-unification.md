## Objective

Collapse the hand-restated charter **activation-key vocabulary** onto its single derived authority
(`pack_manager.YAML_KEY_MAP`, itself from `CHARTER_KIND_TOKENS`) and **fix the live data-loss drift**:
the finalize migration's `ACTIVATION_KEYS` is missing `activated_glossary_packs` (10 vs 11), so it would
silently drop glossary-pack activation on migration (FR-010 / SC-005). Also route the one built-in join
in `pack_manager.py:658` through `built_in_dir` (FR-002 slice). Add a set-equality guard so the
vocabulary can never drift again. **This WP MUST land before Mission 2** (`charter-pack-usage-journey`)
retargets the shared resolver / activation store (C-004).

Read first: `../spec.md` (FR-010, SC-005, C-004), `../contracts/built-in-location-authority.md` (C4.1/C4.2),
`../plan.md` IC-05, `../notes/research-synthesis.md` (WS-C). Ground in `src/charter/activation/pack_manager.py`
(`YAML_KEY_MAP`, the `"built-in"` marker sites at :134/:269/:639/:653/:661 that are NOT joins, and the
join at :658), `src/charter/activation/charter_yaml_io.py` (`_ACTIVATION_KEYS`),

### T017 — Fix the live drift + derive the migration keys (FR-010, C4.2)

hand-written literal tuple with a value **derived from `YAML_KEY_MAP`** (via a cheap plain-tuple constant

### T018 — Derive `charter_yaml_io._ACTIVATION_KEYS` from the authority (FR-010, C4.1)

### T019 — Set-equality guard test (FR-010, C4.1)

and the migration `ACTIVATION_KEYS` are each **set-equal** to the authority derived from `YAML_KEY_MAP`.
Add a focused regression asserting `activated_glossary_packs` is present in both (the exact drift). This
guard is what makes SC-005 CI-enforced.

### T020 — Route the pack_manager built-in join (FR-002)

### T032 — End-to-end finalize-migration test for the glossary-pack drift (SC-005, C4.2)

`tests/charter/test_activation_vocabulary_setequal.py` (or a sibling): construct a project fixture with an
