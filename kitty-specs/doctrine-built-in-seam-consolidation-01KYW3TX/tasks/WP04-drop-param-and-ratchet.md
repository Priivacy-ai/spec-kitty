root calls, exempts the ~20 string markers, plus positive per-kind coverage and anti-vacuity.

## Subtasks

### T013 — Drop `built_in_root` + `_built_in_dir` from `DoctrineService` (FR-003/FR-004)
In `src/doctrine/service.py`: remove the `built_in_root` constructor parameter and the nested
`_built_in_dir` helper that encoded the pre-move `src/doctrine/<kind>/built-in` shape. After this the
service cannot be handed a wrong/empty built-in root — repos self-resolve via `built_in_dir(kind)`
(WP01). Preserve the `SPEC_KITTY_PACKS_ROOT` synthetic-tier override path (C-007) — that is the
supported injection point, unaffected by the param drop. No production behaviour change (C2.2): the
no-explicit-root construction loads exactly what it loads today.

### T014 — The joins-only AST ratchet (NFR-002, C3.1/C3.1b)
New file `tests/architectural/test_built_in_location_authority.py`. AST-scan `src/` and **flag path
joins only**:
- a `resolve_pack_root("built-in") / …` BinOp, **and** its variable-indirected form
  (`x = resolve_pack_root("built-in"); x / …`) — both limbs are load-bearing (a BinOp-only scan
  false-greens the indirected joins);
- a `<path> / "built-in"` filesystem join.
Any such join **outside `src/doctrine/pack_paths.py`** fails the gate and names the offending
`file:line`. **Permit** a bare `resolve_pack_root("built-in")` root call (that IS the seam via
`built_in_root()`), and **exempt** the ~20 legitimate bare `"built-in"` string-literal markers used as
layer/provenance tags: `drg/models.py:330`, `drg/merge.py:917/930/1226/1229`,
`pack_manager.py:134/269/639/653/661`, `mission.py:817/828`, `profiles_cmd.py:60`,
`mission_type.py:1521`, `_doctrine_collect.py:719`, `charter/list_cmd.py:101`, … (a naive constant-scan
false-reds these — the gate must be join-only). Add a **negative bite test**: inject a synthetic
variable-indirected join into a fixture string and assert the gate flags it (proves the gate is not vacuous).

### T015 — Positive per-kind coverage with the #3091 marker (NFR-003/NFR-005, C3.2)
In the same file: for every kind WITH a content dir (the 9), assert `built_in_dir(kind)` lands in an
existing `packs/built-in/<plural>/`, asserted **through `resolve_pack_root(...)`** — NOT a raw
repo-relative `.exists()` (cf. #3036; survives the future wheel-split). Assert the **derived complement**
`{mission_step_contract, template, anti_pattern}` raises, carrying an explicit inline `#3091` marker on
the derived set (NFR-005): adding a fourth exempt kind, or a kind gaining a content dir, must require
editing this marked assertion — it cannot drift silently.

### T016 — Anti-vacuity (NFR-003, C3.3)
In the same file: assert the shipped `agent_profiles` set resolved through the authority is **non-empty**
— so a stale/empty/misconfigured root fails the gate loudly instead of passing vacuously (US2 acceptance
#2; the exact latent false-green this mission exists to kill). Run `ruff` + `mypy` clean on both files.
