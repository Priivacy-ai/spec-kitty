## Objective

Shrink the private re-export shim in `src/charter/activation/context.py` (the `_x as _x` block, roughly lines
25–145) that the context de-god left behind with no removal ticket (FR-011). Re-point the **test**
imports of private symbols to their leaf modules and delete only the re-exports that **no module imports**.
**Critical (post-tasks squad):** several re-exported privates are imported by **production** modules via
function-local `# noqa: PLC0415` cycle-breakers (`from charter.activation.context import _x`) — e.g.
`_build_doctrine_service`, `_build_activation_aware_doctrine_service`, `_default_agent_profile_repository`,
`_render_profile_sections`, `_load_doctrine_selection`, `_iter_org_charter_docs`,
`_read_org_required_selections`, `_ActionDoctrineBundle` (in `context_json.py`, `action_doctrine_bundle.py`,
`doctrine_service_builder.py`, `profile_resolution.py`, `context_renderers/{bootstrap_text,compact_governance,activation_block,selection_block}.py`).
Those re-exports are **load-bearing** and MUST be **retained** — the production importer files are NOT
owned by this WP and MUST NOT be edited (retaining the re-export keeps them working). **No production
behaviour change** and **no change to the public surface** (`__all__` + `build_charter_context*` stay).
Test-only, does not touch any built-in location seam.

Read first: `../spec.md` (FR-011, US3 acceptance #2), `../plan.md` IC-06, `../notes/research-synthesis.md`
(WS-E). Ground in `src/charter/activation/context.py:25-145` (the re-export block) and its `__all__` at :147.

**Owned test set = only the files importing/patching a PRIVATE (`_`-prefixed) `charter.activation.context` symbol.**

## Subtasks

### T021 — Repo-wide census: build the retain-set and the delete-set
Census **both `src/` AND `tests/`** for every `_`-prefixed symbol imported from / patched on
`charter.activation.context`:
`grep -rEn "from (src\.)?charter\.context import|charter\.context\._" src/ tests/`. For each private symbol
in the re-export block, classify:
- **RETAIN** — imported/patched by any module (production OR test) still resolving it via `charter.activation.context`.
  Production function-local `# noqa: PLC0415` importers (see Objective list) force RETAIN; those files are
  unowned and untouched.
- **DELETE** — imported ONLY by the owned test files (or by nothing). These are the true re-export-only
  symbols; repoint their test importers to the leaf, then remove just those `_x as _x` lines.
Map each symbol to its leaf module (the re-export block IS the authoritative map — e.g.
`_render_profile_directives` → `charter.activation.context_renderers.profile_sections`, `_load_action_doctrine_bundle`
→ `charter.activation.action_doctrine_bundle`, `_bundle_root_for_json`/`_project_*`/`_relative_json_path` →
`charter.activation.context_json`, `_render_bootstrap_text` → `charter.activation.context_renderers.bootstrap_text`). Record the
retain/delete lists in the WP evidence.

### T022 — Repoint the owned test files (leaf imports for the DELETE-set; keep RETAIN patch targets)
For each owned test file, change `from charter.activation.context import _sym` → `from <leaf.module> import _sym` for
DELETE-set symbols. For a `patch("charter.activation.context._sym")` whose symbol is in the **RETAIN** set (because a
production function-local importer resolves it via `charter.activation.context`), **leave the patch target at
`charter.activation.context._sym`** — repointing it to the leaf would stop patching the production call path. Only
repoint patch targets whose symbol is DELETE-set. Structural hazard: **multi-line**
`from charter.activation.context import ( … )` blocks (e.g. `tests/charter/test_context.py:14`,
`tests/charter/test_context_selection_render.py`) — split across the correct leaf modules for DELETE-set
symbols, keeping RETAIN-set and public names on `charter.activation.context`.

### T023 — Remove only the DELETE-set re-exports; keep RETAIN-set + public surface
Delete from the `context.py` re-export block only the `_x as _x` lines whose symbol is DELETE-set (zero
importers in `src/` and `tests/` after T022). **Keep** every RETAIN-set re-export (production depends on
it) and keep `__all__` + all public names intact (FR-011 "no change to the public surface"). This
"retirement" is a shrink, not a wholesale block deletion — the shim's remaining lines are the load-bearing
production cycle-breakers, not dead test scaffolding. Run the owned tests + `ruff` + `mypy` clean.
