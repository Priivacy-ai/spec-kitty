# Красный тест перехода в ревью

## Проверяемый контракт

Реальный `move-task --owned-checkout` должен переводить `code_change` пакет из
`in_progress` в `for_review`, используя `planning_commit_sha` выбранной рабочей
копии как отдельную неизменяемую базу сравнения. Вызов из primary не должен
читать или изменять primary и соседнюю рабочую копию.

## Доказанная подготовка

- `planning_commit_sha` существует как 40-символьный Git commit;
- он является предком реализационного `HEAD`;
- реализационный `HEAD` отличается от `planning_commit_sha`;
- перед переходом создан реальный коммит в заявленном `app.py`;
- назначение и запуск выполнены через реальный CLI в выбранной рабочей копии.

## Результат

Целевой тест
`test_move_task_enters_review_against_selected_checkout_planning_commit`
намеренно красный: текущая реализация возвращает
`OWNED_TRANSITION_UNSUPPORTED` до review-gates. Это воспроизводит недостающий
контракт после проверки пригодности базы, а не ошибку фикстуры или парсера.

Контрольный тест чтения выбранной копии прошёл: `1 passed`. Проверка
`ruff check tests/integration/test_owned_checkout_move_task.py` прошла.

Рабочее поведение не изменено. Следующий пакет должен провести выбранный корень
и зафиксированный `planning_commit_sha` через существующие pre-review gates;
T010 остаётся открытой.
