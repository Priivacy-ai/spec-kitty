# Назначение и запуск в выбранной рабочей копии

Дата: 2026-08-31. Исходная ревизия: `326611f76` с отдельным красным
воспроизведением. Это промежуточный локальный результат согласованного ремонта.

## Реализовано

`move-task --owned-checkout` проводит проверенный корень через чтение документов,
оба чтения статуса, переход, назначение исполнителя и сохранение заметок.
Статусы и annotations записываются транзакционно в выбранной ветке. Чтение
политики основной копии и проверки индекса сохранены. Общие адаптеры чтения
и commit также передают явно выбранный корень; без флага прежний путь сохранён.

Поддержаны назначение и запуск. Ревью, возврат, завершение, обходы проверок,
отключённый auto-commit и активная синхронизация отклоняются заранее. Последнее
ограничение нужно потому, что существующая синхронизация документов повторно
читает metadata основной копии. Она не отключается молча, её расширение остаётся
незавершённой частью общего ремонта. Отдельная база сравнения понадобится для
ревью, которое в текущем варианте недоступно.

Переход и последующая annotation не являются одной общей атомарной операцией:
при техническом сбое annotation переход уже может быть committed. Проверка
такого сбоя требует ненулевой exit code и отсутствия ложного успеха. Отката
сохранённого перехода этот промежуточный результат не обещает.

## Проверки

- Итоговый расширенный набор: **27 passed**; после независимого чтения основная
  сессия отдельно повторила назначение с PID, повторный отказ, сбой annotation
  и оба варианта error envelope: **4 passed**.
- Первоначальный новый набор: 22 успешных сценария через реальные Git worktrees
  и Typer entrypoint. Выбранная копия доступна из своего, основного и соседнего
  каталогов; одноимённые документы соседей не используются.
- Связанные прежние интеграционные тесты: 82 успешных сценария.
- Совместимость команд, adapters, guards, transition и durability: 518 успешных
  сценариев, 3 падения. Все три воспроизведены на архиве исходной ревизии:
  `TyperGroup` не проходит старый `isinstance(click.Group)` и два теста передают
  Windows backslash-пути в `git show`. Эти тесты не исправлялись и не пропускались.
- Mypy для шести модулей: 7 прежних ошибок `Any`/import typing в двух файлах.
  Архив исходной ревизии дал те же семь сообщений и строки. Проверка не зелёная.
- Ruff для всех семи изменённых Python-файлов: успешно.
- Штатные проверки структуры документов, требований, зависимостей и conflicts
  пройдены: один пакет, 20 требований, из них 15 функциональных. Это вызовы
  validators, не полная команда финализации или приёмки. JSON/HTML карты совпали
  с хешами lock; `git diff --check` успешен. Новая проза и заголовки по-русски.
- Отдельные проверки отказов и совместимости ошибки: 16 успешных сценариев.
- Значимая мутация второго чтения: `effective_root=None` направляет чтение
  в основную копию с корректным JSON другого пакета. Тест падает из-за отсутствия
  канонического статуса WP01, а не parser/fixture. Мутация восстановлена.
- Мутация ожидаемого статуса на `planned` дала точное содержательное падение
  `in_progress != planned`. Ожидание восстановлено.

Все запуски используют временные HOME, USERPROFILE, SPEC_KITTY_HOME, APPDATA,
LOCALAPPDATA, TEMP и TMP. Корневой CLI, глобальная установка и реальная работа
исходного навыка не запускались. Тест активной синхронизации останавливается
на предварительной проверке, не запускает transport или capture.

## Независимое чтение

Первое чтение обнаружило изменение прежнего error envelope и риск неверной
синхронизации документов. Обработчик ошибок ограничен новым режимом; добавлены
проверки envelope и ErrorLogged. Активная синхронизация явно запрещена до записи
через тот же предикат, который использует её обработчик. После исправлений
reviewer одобрил только этот ограниченный результат, не полное расширение.
Тесты reviewer не запускал; основная сессия завершила повторные проверки выше.

## Сохранение и границы

Результат сохранён только в документах этой работы; связанный issue получает
ссылку, без дублирования доказательств. Личная память, RAG и полные журналы
не переносятся. Карта кода обновлена совместно в JSON, HTML и lock.
Сохранение сессии направлено в существующие документы проекта; отдельный
дневник не создавался. Hermes Kanban MCP недоступен в текущем наборе инструментов.

Общий статус остаётся частичным: полный цикл ревью/возврата, синхронизация,
проверка покрытия всего расширения и формальная приёмка не завершены.
Следующий разрешённый пакет продолжает эту же работу без установки и публикации.
Отдельный ремонт создания execution workspace остаётся в очереди.
