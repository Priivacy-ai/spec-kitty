# Implementation Plan: Governance at the deciding gate (#3685 + #3682)

## Summary

Move the decision-documentation obligation **off the `implement` action** to the **deciding gates**, and make those gates capture it — landing both halves in one mission so no window opens where an architecture-altering decision is captured neither at implement nor at the gate. Secondary: give the doctrine-delivery layer the enforcement **order** and tension **arbiter delivery** it lacks, plus a regression gate so a `required` decision-documentation directive can never silently re-enter `implement`.

Four implementation concerns, two of them a coupled core:
- **IC-01 (policy)** + **IC-04 (realization)** are the coupled core (C-004: land together).
- **IC-02 (enforcement lattice + gates)** and **IC-03 (arbiter delivery)** are additive hygiene, independently shippable.

### IC-01 — Move DIRECTIVE_003 off `implement`, onto `review` (US1 / FR-005)
- **Approach**: trace + resolve the `review→003` mint path; delete the 003 line from `implement/index.yaml`; add to `review/index.yaml`; `doctrine regenerate-graph`; verify `--check`/orphan-lint/reachability green and 003 still reachable from `plan/specify/tasks/retrospect`.

- **Depends on**: nothing to start; **co-lands with IC-04** (C-004).

### IC-02 — Enforcement rank + lattice gate + class-level implement guard + reconcile promotion (US3 / FR-001–004)
- **Approach**: add explicit rank + rank-based `__lt__` to `Enforcement` (single authority); in `consistency_check.py`, add (a) the `reconciles_tension` directive→directive lattice gate (reuse `_tension_reconciled_urns`, skip tactic targets) and (b) the class-level "no `required` decision-documentation directive scoped on `implement`" gate; raise the reconciler to `lenient` + add `explicit_allowances`.
- **Tests (red-first)**: seeded advisory-over-lenient fixture fails; tactic-target skipped; required-decision-doc-on-implement fixture fails; shipped corpus passes after promotion; rank-driven (rename-proof) comparator test; reconciler loads at lenient.
- **Depends on**: independent; the class-level gate (b) protects IC-01.

### IC-03 — Deliver the arbiter as an arbiter (US4 / FR-009)
- **Approach**: extend `ResolvedContext` + `_ActionDoctrineBundle` with additive `tension_arbiters` / `unarbitrated_tensions`; have `resolve_context` populate them by walking `reconciles_tension`/`in_tension_with`, reusing the progressive-disclosure traversal (no second graph walk); no version bump.
- **Tests (red-first)**: bundle with 024+025 exposes `reconcile→(024,025)`; reconciler-less declared pair in `unarbitrated_tensions`; common-case latency unchanged.
- **Depends on**: IC-02's rank only if it annotates rank (optional); otherwise independent.

### IC-04 — Deciding gates capture the evidence (US2 / FR-006–008)
- **Task 0**: re-derive current-main state vs #3235; scope only the durable remainder.
- **Approach**: add an `APPROVED` arm to `_mt_hop_policy_metadata` (+ `_binding_role_for_lane`) so the approval event carries `policy_metadata` + `review_ref`; relax the `!= "changes_requested"` guard in `_persist_approved_review_cycle` so first-pass approve auto-authors an `approved` `review-cycle-N.md` via the existing symmetric writer; make `accept` populate matrix rows from recorded evidence before recompute (or block loudly), closing the `cannot_evaluate`/`--allow-fail` silent-pass.
- **Tests (red-first)**: approved event carries `policy_metadata`+`review_ref`; first-pass approve writes `review-cycle-1.md` (verdict approved, `reproduction_command`); accept populates or loudly blocks a scaffold matrix.
- **Depends on**: **co-lands with IC-01** (C-004). Parent epic #3044.
